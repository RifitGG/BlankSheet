# Чистый лист - Интерактивная доска для совместной работы

Веб-приложение для совместного рисования и работы в режиме реального времени. Поддерживает множество пользователей, работающих на одной доске одновременно с синхронизацией через WebSocket.

## Основные возможности

- **Многопользовательское рисование в реальном времени** - до 10 участников на одной доске
- **Инструменты рисования** - кисть, ластик, геометрические фигуры (линии, прямоугольники, круги)
- **Работа с объектами** - добавление текста и изображений с возможностью перемещения
- **Автоматическое сохранение** - снимки доски сохраняются каждые 30 секунд
- **История изменений** - отмена и повтор действий
- **Персональный дашборд** - управление созданными и присоединенными досками
- **Система аутентификации** - регистрация и вход с использованием JWT токенов
- **Адаптивный интерфейс** - работает на десктопах, планшетах и смартфонах

## Технологический стек

### Backend
- **Flask 3.0.0** - веб-фреймворк
- **Flask-SocketIO 5.3.5** - WebSocket соединения для реального времени
- **MySQL 8.0+** - реляционная база данных
- **PyJWT 2.8.0** - генерация и валидация JWT токенов
- **bcrypt 4.1.2** - хеширование паролей
- **eventlet 0.33.3** - асинхронный сервер

### Frontend
- **Vanilla JavaScript** - без дополнительных фреймворков
- **Socket.IO Client 4.5.4** - WebSocket клиент
- **HTML5 Canvas** - рендеринг графики
- **CSS3** - современный адаптивный дизайн

## Требования к системе

- Python 3.8 или выше
- MySQL 8.0 или выше
- 512 MB RAM (минимум)
- 100 MB свободного места на диске

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/RifitGG/BlankSheet
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/Mac:**
```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка базы данных

Создайте базу данных MySQL:

```sql
CREATE DATABASE whiteboard_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Создайте пользователя и предоставьте права:

```sql
CREATE USER 'whiteboard_user'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON whiteboard.* TO 'whiteboard_user'@'localhost';
FLUSH PRIVILEGES;
```

### 5. Конфигурация

Скопируйте файл `.env.example` в `.env`:

```bash
copy .env.example .env  # Windows
cp .env.example .env    # Linux/Mac
```

Отредактируйте `.env` файл и укажите параметры подключения к базе данных:

```env
DB_HOST=localhost
DB_USER=whiteboard_user
DB_PASSWORD=your_password
DB_NAME=whiteboard
SECRET_KEY=your_secret_key_here
```

### 6. Инициализация базы данных

```bash
python init_db.py
```

Эта команда создаст все необходимые таблицы в базе данных.

### 7. Запуск приложения

```bash
python run.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

Для быстрого запуска на Windows можно использовать:
(батник отсутствует)
```bash
start.bat
```

## Использование

### Регистрация и вход

1. Откройте главную страницу
2. Нажмите "Регистрация"
3. Заполните форму (имя пользователя, email, пароль)
4. После успешной регистрации вы будете автоматически авторизованы

### Создание доски

1. На дашборде нажмите "Создать новую доску"
2. Введите название доски
3. Система сгенерирует уникальный 8-символьный код
4. Поделитесь кодом с другими участниками

### Присоединение к доске

1. На дашборде нажмите "Присоединиться к доске"
2. Введите 8-символьный код доски
3. После проверки вы будете добавлены как участник

### Инструменты рисования

- **Выделение (V)** - выбор и перемещение объектов (текст, изображения)
- **Кисть** - свободное рисование
- **Ластик** - стирание нарисованного
- **Текст** - добавление текстовых блоков
- **Изображение** - загрузка и размещение изображений
- **Линия** - рисование прямых линий
- **Прямоугольник** - рисование прямоугольников
- **Круг** - рисование кругов

### Горячие клавиши

- `Ctrl+Z` - отменить действие
- `Ctrl+Y` - повторить действие
- `V` - переключиться на инструмент выделения

## API Endpoints

### Аутентификация

#### POST `/api/auth/register`
Регистрация нового пользователя

**Тело запроса:**
```json
{
  "username": "string",
  "email": "string",
  "password": "string"
}
```

**Ответ (201):**
```json
{
  "success": true,
  "message": "Registration successful",
  "token": "jwt_token",
  "user": {
    "id": 1,
    "username": "string",
    "email": "string"
  }
}
```

#### POST `/api/auth/login`
Вход в систему

**Тело запроса:**
```json
{
  "username": "string",
  "password": "string"
}
```

**Ответ (200):**
```json
{
  "success": true,
  "message": "Login successful",
  "token": "jwt_token",
  "user": {
    "id": 1,
    "username": "string",
    "email": "string"
  }
}
```

#### POST `/api/auth/logout`
Выход из системы

**Ответ (200):**
```json
{
  "success": true,
  "message": "Logout successful"
}
```

#### GET `/api/auth/verify`
Проверка JWT токена

**Ответ (200):**
```json
{
  "success": true,
  "user": {
    "id": 1,
    "username": "string",
    "email": "string"
  }
}
```

### Управление досками

#### POST `/api/board/create`
Создание новой доски

**Заголовки:** `Authorization: Bearer {token}`

**Тело запроса:**
```json
{
  "name": "string"
}
```

**Ответ (201):**
```json
{
  "success": true,
  "message": "Board created successfully",
  "board": {
    "id": 1,
    "code": "ABC12345",
    "name": "string"
  }
}
```

#### POST `/api/board/join`
Присоединение к доске по коду

**Заголовки:** `Authorization: Bearer {token}`

**Тело запроса:**
```json
{
  "code": "ABC12345"
}
```

**Ответ (200):**
```json
{
  "success": true,
  "message": "Successfully joined",
  "board": {
    "id": 1,
    "code": "ABC12345",
    "name": "string"
  }
}
```

#### GET `/api/board/my-boards`
Получение списка досок пользователя

**Заголовки:** `Authorization: Bearer {token}`

**Ответ (200):**
```json
{
  "success": true,
  "boards": [
    {
      "id": 1,
      "board_code": "ABC12345",
      "name": "string",
      "owner_name": "string",
      "participant_count": 3
    }
  ]
}
```

#### GET `/api/board/{board_code}`
Получение информации о доске

**Заголовки:** `Authorization: Bearer {token}`

**Ответ (200):**
```json
{
  "success": true,
  "board": {
    "id": 1,
    "board_code": "ABC12345",
    "name": "string",
    "owner_id": 1,
    "participants": [
      {
        "id": 1,
        "username": "string",
        "is_online": true
      }
    ]
  }
}
```

#### DELETE `/api/board/{board_code}/delete`
Удаление доски (только владелец)

**Заголовки:** `Authorization: Bearer {token}`

**Ответ (200):**
```json
{
  "success": true,
  "message": "Board deleted successfully"
}
```

#### DELETE `/api/board/{board_code}/leave`
Покинуть доску

**Заголовки:** `Authorization: Bearer {token}`

**Ответ (200):**
```json
{
  "success": true,
  "message": "Successfully left the board"
}
```

## Решение проблем

### Приложение не запускается

**Проблема:** `ModuleNotFoundError: No module named 'flask'`

**Решение:** Убедитесь, что активировано виртуальное окружение и установлены зависимости:
```bash
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

### Ошибка подключения к базе данных

**Проблема:** `mysql.connector.errors.ProgrammingError: Access denied`

**Решение:** 
1. Проверьте правильность данных в `.env` файле
2. Убедитесь, что MySQL сервер запущен
3. Проверьте права пользователя базы данных

### WebSocket соединение не устанавливается

**Проблема:** Сообщения не синхронизируются между клиентами

**Решение:**
1. Проверьте, что порт 5000 не занят другим приложением
2. Проверьте настройки firewall
3. Убедитесь, что eventlet установлен корректно

### Изображения не загружаются

**Проблема:** `OSError: [Errno 28] No space left on device`

**Решение:** Освободите место на диске или измените путь `UPLOAD_FOLDER` в `config.py`

## Производительность

- **Рекомендуемое количество одновременных досок:** до 100
- **Максимум участников на одной доске:** 10
- **Размер загружаемых изображений:** до 5 MB
- **Частота автосохранения:** каждые 30 секунд
- **Максимальный размер истории:** 50 действий

## Безопасность

- Пароли хешируются с использованием bcrypt (cost factor 12)
- JWT токены используют HS256 алгоритм
- Все SQL запросы используют параметризацию для защиты от SQL injection
- Сессии автоматически истекают через 24 часа
- CORS настроен для безопасной работы с WebSocket

## Разработка

### Запуск в режиме разработки

```bash
python run.py
```

Flask запустится с `debug=True`, что обеспечивает:
- Автоматическую перезагрузку при изменении файлов
- Подробные сообщения об ошибках
- Интерактивный отладчик в браузере

### Структура кода

Проект следует архитектуре MVC (Model-View-Controller):

- **Models** (`app/models/`) - бизнес-логика и работа с БД
- **Views** (`app/templates/`) - HTML шаблоны
- **Controllers** (`app/routes/`) - обработка HTTP запросов
